# Maui Calculator (.NET MAUI)

تطبيق آلة حاسبة حديث ومتقدم مبني باستخدام إطار العمل **.NET MAUI** لنظام Windows.

## المميزات
- **الوضع القياسي (Standard):** العمليات الحسابية الأساسية، النسبة المئوية، الجذور، الذاكرة (M+, M-, MR, MC, MS).
- **الوضع العلمي (Scientific):** دوال مثلثية، لوغاريتمات، قوى، أسس، وعمليات متقدمة.
- **إعدادات المظهر (Themes):** دعم الوضع الفاتح (Light) والداكن (Dark) ووضع النظام.
- واجهة مستخدم متجاوبة وأنيقة مستوحاة من آلة حاسبة ويندوز الرسمية.

## متطلبات التشغيل
- [.NET 8.0 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)
- إطار عمل .NET MAUI لـ Windows Desktop

## طريقة التشغيل
يمكن تشغيل المشروع باستخدام الأمر التالي:
```bash
dotnet run --project MauiCalculator -f net8.0-windows10.0.19041.0
```
أو عبر فتح ملف `MauiCalculator.sln` في Visual Studio 2022.
